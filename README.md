## Problem
A Musanze potato cooperative needs a local, offline decision-support tool that (1) estimates harvest
tons (regression), (2) flags farms at high production risk, i.e. yield per hectare below the median
(classification), and (3) groups farms with similar conditions (clustering). The service is a
classroom prototype and **does not replace an agronomist**.

## Setup and run (Python 3.14 tested; tested on Linux)
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run_all.py --student-id <username@ines.ac.rw> --seed <LLLL>
python predict.py --json samples/valid.json
python predict.py --json samples/invalid.json      # shows validation errors (exit code 2)
pytest -q
uvicorn app:app --host 127.0.0.1 --port 8000       # docs at http://127.0.0.1:8000/docs
```
`run_all.py` rejects any seed that is not the last four digits of the student id.

## Layout
- `run_all.py` – one-command pipeline; `predict.py` – CLI inference; `app.py` – FastAPI.
- `src/` – `config`, `validation`, `data_generation`, `preprocessing`, `modeling`, `clustering`,
  `plots`, `schemas`, `inference`, `pipeline`.
- `data/generate_data.py` + `data/AI_A2_<REGDIGITS>.csv` – generator and generated CSV.
- `models/` – saved pipelines (`*.joblib`) and `model_info.json`.
- `artifacts/` – `regression_metrics.json`, `classification_metrics.json`, `clustering_report.json`,
  `test_predictions.csv`, `data_fingerprint.txt`, `data_validation_report.json`, `plots/*.png`.
- `tests/` – pytest suite (valid inference, missing field, wrong type, range errors,
  reproducibility, leakage, API responses).

## Design notes
- Fixed stratified 80/20 split, `random_state = LLLL`. Imputation, scaling and one-hot encoding live
  inside scikit-learn `Pipeline`/`ColumnTransformer`, so they are fitted on training rows only and
  reused identically at inference.
- Duplicates are removed in cleaning; missing `soil_moisture_pct`/`fertilizer_kg` are median-imputed
  inside the pipeline.
- Leakage control: `yield_tons`, yield per hectare and `high_risk` are never features
  (`src/validation.check_no_leakage`).
- Model selection uses 5-fold cross-validation on the **training** set (RMSE for regression, F1 for
  classification); the test set is only used for reporting.
- Clustering uses scaled inputs only; K=2…6 compared by silhouette score.
- No extra packages beyond those in `requirements.txt` (`uvicorn` runs the API; `httpx` is needed by
  FastAPI's `TestClient`).

## API

```bash
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" \

```

## Known limitations
Synthetic data with a known formula; metrics are optimistic and do not transfer to real farms.
Clusters are weakly separated. Predictions need human review. Do not use for credit, insurance or
public-service decisions.
